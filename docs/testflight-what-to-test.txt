Winnow: the same wallet, rewritten in Lean

New in 0.9.29
1. Background continued sync (iOS 26): pull to refresh, tap Sync now or Retry, turn on Verify from genesis, or restore/import a wallet, then swipe away. A Live Activity shows "Syncing Bitcoin" (or "Syncing Signet") with header/block progress — never balances or wallet names — and keeps syncing until up to date, or stops cleanly if you cancel from the Live Activity.
2. Cleaner iCloud backup & plain-English errors: Home no longer nudges you to save manual backup files when iCloud isn't synced; actionable iCloud issues link straight to iCloud backup settings, while brief offline retries stay quiet. Error screens should never show raw "The operation couldn’t be completed. (WalletCore.…)" codes.
3. Reorgs keep a pending send's change coin counted rather than showing 0 until reconfirmation.

Since 0.9.28: profiles, multi-device sync, SegWit v0 multisig, and person cards.
- Profiles: tap the open profile on Home to switch instantly, rename, or add/restore another profile; each profile keeps its own accounts and "Watching" lists the rest.
- Multi-device sync (iCloud): multisig accounts, paired Ledgers, and pending PSBTs follow your devices under the same Apple Account; Settings → Backup → iCloud backup reports each other device's status.
- SegWit v0 multisig (`wsh(sortedmulti(…))`) and person cards (Receive → "From one person") continue to work as before, with whole-number fee arithmetic.

This build is Winnow rewritten in Lean 4, with no Swift. It updates the App Store's Winnow Wallet in place and keeps its wallet, receive labels and iCloud backups. Saved people, Signers and multisig accounts from the Swift app are set aside on the phone (not deleted) and start empty: pair your Ledger again under Settings → Security → Hardware wallets and keys. Please try it on a phone whose wallet you could restore from its recovery words.

Install over the current app

1. With the App Store's Winnow holding a wallet, install this build from TestFlight. The same wallet, balance and Activity must appear, and it must sync to "Up to date".
2. Settings → Backup: iCloud backup should show "Backed up" with a time. On a second device signed into the same Apple Account, a fresh install should offer "Restore your iCloud wallet" and restore the same wallet.

Report bugs at https://github.com/winnowwallet/winnow-lean/issues with app version, device, Ledger model, network and steps. Never include recovery words, private keys or backup files.
